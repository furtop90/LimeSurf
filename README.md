# LimeSurf
LimeSurf is a web browser written in Python with a PyQt5 interface using the Qt5 webview. The goal of the browser is to be a browser that uses little RAM, can block ads, and can be installed on basic PCs.

## 🛠️ Requisitos del Sistema

*   **Sistema Operativo:** Windows 10 / 11 
*   **Lenguaje:** Python 3.10 o superior
*   **Dependencias principales:**
    *   `PyQt5` (Interfaz gráfica)
    *   `PyQtWebEngine` (Componente del motor web)
