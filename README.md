# LimeSurf
LimeSurf is a web browser written in Python with a PyQt5 interface using the Qt5 webview. The goal of the browser is to be a browser that uses little RAM, can block ads, and can be installed on basic PCs.

## ✨ Características

*   🚀 **Motor QtWebEngine:** Basado en Chromium, lo que garantiza una excelente compatibilidad con los estándares web modernos (HTML5, CSS3, JavaScript).
*   🎨 **Interfaz Limpia:** Barra de direcciones inteligente, botones de navegación clásicos (Atrás, Adelante, Recargar, Inicio) e indicador de estado de carga.
*   📦 **Totalmente Portátil:** Ideal para entornos portátiles; se ejecuta de forma independiente directamente desde una carpeta o memoria USB sin alterar el sistema operativo.
*   🔒 **Privacidad Ligera:** Sin rastreadores comerciales ni telemetría en segundo plano, consumiendo menos recursos que los navegadores convencionales.

## 🛠️ Requisitos del Sistema

*   **Sistema Operativo:** Windows 10 / 11 o Linux (Ubuntu, Debian, Fedora, etc.)
*   **Lenguaje:** Python 3.10 o superior
*   **Dependencias principales:**
    *   `PyQt5` (Interfaz gráfica)
    *   `PyQtWebEngine` (Componente del motor web)
